# 🚕 Uber Data Engineering Project on Azure

An end-to-end data engineering project that simulates an Uber-style ride-booking platform and demonstrates how modern Azure data services can be used to build a scalable batch and real-time data pipeline.

The project combines **Azure Data Factory, Azure Event Hubs, Azure Databricks, PySpark, Spark Structured Streaming, Spark Declarative Pipelines, Azure Data Lake Storage Gen2, and FastAPI** to ingest, process, transform, and model ride-booking data for analytics.

> **Project type:** End-to-End Data Engineering / Batch + Real-Time Streaming  
> **Domain:** Ride Booking / Transportation  
> **Cloud:** Microsoft Azure  
> **Primary technologies:** Azure Data Factory, Azure Event Hubs, Azure Databricks, PySpark, Spark, ADLS Gen2

---

## 📌 Project Overview

This project simulates a ride-booking data platform similar to the backend data flow of a ride-hailing application.

The system handles two major types of data:

1. **Historical / batch data** – bulk ride and reference data loaded through Azure Data Factory.
2. **Real-time ride events** – new ride-booking events generated by a FastAPI application and streamed through Azure Event Hubs.

The data is then processed in Azure Databricks using a **Medallion Architecture**:
